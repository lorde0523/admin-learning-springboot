# 작업 방식 메모

## 서브 에이전트 사용 원칙

토큰 소모를 줄이기 위해 서브 에이전트는 최소한으로 사용한다.

- 작은 수정: 메인 에이전트가 바로 처리하고 서브 에이전트는 사용하지 않는다.
- 일반 기능 수정: 메인 에이전트가 직접 구현하고 필요한 테스트만 실행한다.
- 큰 구조 변경: 메인 에이전트가 우선 진행하고, 위험도가 높을 때만 리뷰 에이전트 1명을 검토한다.
- 병렬 에이전트: 사용자가 명시적으로 요청하지 않으면 사용하지 않는다.
- 설명/문서 요청: 도구 호출과 파일 탐색을 최소화하고 필요한 파일만 확인한다.

기본값은 "직접 구현 + 필요한 검증만 수행"이다.
