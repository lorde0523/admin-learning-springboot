# 모바일 React 학습 과정

Vue 경험이 있는 입문자가 휴대폰으로 React를 익히고, 이 저장소의 공통 UI와 공통 로직을 이해하기 위한 과정이다.

## 학습 방법

한 번에 한 단계만 읽는다. 코드를 외우기보다 실행 결과를 먼저 예상한 뒤 정답을 확인한다.

1. 설명과 Vue 비교를 읽는다.
2. 예제 코드를 손으로 가리고 결과를 예상한다.
3. 연습 문제에 답한다.
4. `정답과 해설`을 펼쳐 이유까지 확인한다.
5. 마지막 세 문장을 자신의 말로 다시 설명한다.

휴대폰에서는 긴 코드를 입력하지 않는다. 빈칸에 들어갈 한두 줄을 메모 앱에 적는 정도면 충분하다.

## 진도 기준

각 단계의 문제를 전부 맞힐 필요는 없다. 다음 두 가지를 설명할 수 있으면 다음 단계로 넘어간다.

- 예제에서 화면이 왜 그렇게 바뀌는가?
- 새로 배운 기능을 언제 사용하고 언제 사용하지 않는가?

설명이 막히면 정답을 다시 읽고 비슷한 예제를 직접 하나 만들어 본다.
